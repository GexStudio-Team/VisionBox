Qué es VisionBots

Una caja inteligente que reconoce objetos con cámara e IA, los registra automáticamente y permite gestionarlos desde una web: saber qué hay, dónde está y su historial. El MVP actual ya sirve para registrar y consultar el inventario de forma manual mientras la IA se entrena con las imágenes que se vayan recolectando.

Problemas resueltos

  • Docker Desktop no instalable (pide permisos de administrador).

    Solución: PostgreSQL instalado directamente en Ubuntu WSL. Docker queda documentado como alternativa cuando se pueda instalar.

  • WSL con error REGDB_E_CLASSNOTREG.

    Se reparó la instalación de WSL y se instaló Ubuntu 26.04 correctamente.

  • Conexiones TCP Windows→WSL inestables.

    El túnel localhost de WSL corta conexiones persistentes. Solución: backend y base de datos corren juntos dentro de WSL (loopback nativo, estable). El frontend en Windows se comunica por HTTP normal.

  • La VM de WSL se apagaba sola al cerrar la última terminal.

    Cada sesión de un solo uso dejaba el sistema sin API. Solución: sesión persistente de WSL en segundo plano desde el inicio de sesión de Windows que mantiene encendida la VM. Probado con 6/6 peticiones estables sin tocar la VM.

  • Conexiones que se colgaban sin límite.

    Se añadió connect_timeout=5 y verificación previa de conexión en el pool para que un corte de red falle rápido y se recupere.

Infraestructura y sistema operativo

TérminoDescripción
Windows 11 (25H2)El sistema operativo del equipo donde corre todo.
WSL 2"Windows Subsystem for Linux 2": tecnología de Microsoft para correr Linux dentro de Windows sin instalar otro sistema.
Ubuntu 26.04 LTSLa distribución de Linux instalada dentro de WSL (el "sistema operativo invitado").
VM (máquina virtual)El entorno Linux aislado que WSL crea; tiene su propia memoria y disco.
KernelEl núcleo del sistema Linux (aquí, 6.18) que gestiona el hardware y los procesos.
systemdEl sistema de servicios de Linux: enciende y controla programas automáticamente.
Servicio / systemctlUn programa que queda corriendo en segundo plano. systemctl status lo consulta, start/stop lo detiene o inicia.
Docker DesktopPrograma para correr aplicaciones en "contenedores". Pidió permisos de administrador y por eso se sustituyó por PostgreSQL directo en WSL.
compose.yamlArchivo de Docker que define los servicios (base de datos, etc.). Queda como alternativa documentada.
.wslconfigArchivo de configuración de WSL en Windows. Se probó "red espejo" (mirrored); quedó en el modo NAT por defecto.
Relay / túnel localhostEl mecanismo de WSL que permite que Windows alcance con "localhost" los puertos que corren dentro de Linux.
NATModo de red por defecto de WSL: la VM tiene su propia IP interna y Windows se comunica por el túnel.
Keep-aliveUna sesión persistente que mantiene encendida la VM de WSL para que la API nunca se "duerma".
Carpeta de Inicio (Startup)Carpeta de Windows que ejecuta programas automáticamente al iniciar sesión; allí vive VisionBots-KeepWSL.cmd.
PowerShellLa terminal y lenguaje de comandos de Windows que se usó para instalar, probar y operar.
